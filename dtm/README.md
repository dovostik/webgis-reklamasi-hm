# DTM Kontur 3D

Aplikasi web offline (PWA) untuk membentuk DTM 3D, kontur bergradasi (ungu = terdalam),
dan selimut orthofoto dari file Surpac STR, CSV, TXT, XYZ, Excel, LAS, atau DXF.

Alamat: https://dovostik.github.io/webgis-reklamasi-hm/dtm/

## Pasang di HP Android
1. Buka alamat di atas di Chrome saat online, tunggu tampilan 3D muncul.
2. Ketuk **Pasang di layar utama** (atau menu titik tiga > Instal aplikasi).
3. Buka sekali lagi dari ikon selagi online agar pembaca GeoTIFF dan Excel ikut tersimpan.
4. Setelah itu aplikasi bisa dipakai tanpa sinyal.

## Data
- Survei (STR/CSV) dan orthofoto tersimpan di HP masing-masing (IndexedDB), tidak di repository ini.
- Unggah data situasi sebagai **Ganti semua**, lalu survei harian sebagai **Update area**.
- Jangan commit file data survei perusahaan ke repository ini (repository publik).
